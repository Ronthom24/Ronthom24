# Hi, I'm Ronnie Thomson 👋

I build full-stack web apps and data/ML products, and I ship them live rather than leaving them on localhost.
Every project below is built end to end by me, from the database and API to the deployed UI.

## Projects

### [CricOptics](https://criclens-ochre.vercel.app): IPL & WPL auction analysis
Auction history, player price estimates, a best-XI-for-a-budget builder and a WPL auction forecast, on top of ball-by-ball match data.
**Stack:** Next.js 14 · Tailwind · shadcn/ui · FastAPI · scikit-learn · PostgreSQL (Neon) · Vercel · Render
🔗 [Live site](https://criclens-ochre.vercel.app)

### [MUN Buddy](https://github.com/Ronthom24/MUN_Buddy): Model UN conference platform
Registration, committee assignment, announcements, QR attendance, results and verifiable certificates, with separate organizer, delegate and admin views.
**Stack:** Next.js (App Router) · TypeScript · Tailwind · Node/Express · PostgreSQL (Supabase) · Vercel · Render
🔗 [Live site](https://mun-buddy-mu.vercel.app) · [Code](https://github.com/Ronthom24/MUN_Buddy)

### [Cric Auction IQ](https://github.com/Ronthom24/IPL-Auction-Analysis): IPL auction price predictor
Predicts auction prices from real player stats across 941 auctions (2009-2026), explains each prediction, and ranks value-for-money picks and franchise spending.
**Stack:** Python · pandas · scikit-learn (Random Forest) · SHAP · Streamlit
🔗 [Live app](https://cric-auction-iq.streamlit.app) · [Code](https://github.com/Ronthom24/IPL-Auction-Analysis)

### [Sangamam 2026](https://sangamam2k26.netlify.app): event site with UPI ticket booking
Landing page and booking flow for a 500-family community event: UPI deep links with a QR fallback, payment proof uploaded to Google Drive, bookings logged to Google Sheets for volunteer verification, plus a weighted lucky draw.
**Stack:** HTML · CSS · JavaScript · Google Apps Script · Google Sheets/Drive · Netlify
🔗 [Live site](https://sangamam2k26.netlify.app) · [Code](https://github.com/Ronthom24/Onam-Booking-app)

### Pitchside: football learning platform (publishing soon)
Helps beginners learn the game, explore tactics and browse real clubs, players and competitions, and find a club that matches them.
**Stack:** React · TypeScript · Vite · Tailwind CSS · FastAPI · SQLAlchemy · PostgreSQL (Neon)

### AC Twin: carbon and water footprint tracker (team project)
Student-focused tracker for air-conditioner energy, carbon and water use, with a browser extension and ML-based usage nudges. Built as a team mini-project.
**Stack:** React · TypeScript · Vite · Tailwind CSS · Python · scikit-learn · Docker
